# Hadoop-Sequenzdateiübertragungen für ausgehende Dateien aktivieren {#enable-hadoop-sequence-file-transfers-for-outbound}

Sie können ausgehende Batch-Übertragungen binärer [!DNL Hadoop Sequence Files] ([!DNL SEQ]) für Audience Manager-Kunden aktivieren.

So aktivieren Sie [!DNL SEQ] ausgehende Dateiübertragungen:

1. Wählen Sie das Unternehmen und das Ziel aus, für das Sie [!DNL SEQ] ausgehende Dateiübertragungen aktivieren möchten.
1. Scrollen Sie in der **[!UICONTROL Edit Destinations]** nach unten zu **[!UICONTROL Batch Data]**.
1. Protokoll auswählen: **[!UICONTROL FTP]** oder **[!UICONTROL S3]**.
1. Format auswählen: **[!UICONTROL AAM-Outbound-SEQ (415)]**.
1. Bestätigen Sie den Vorgang, indem Sie unten auf der Seite auf **[!UICONTROL Save]** klicken. Der Kunde kann jetzt Hadoop-Sequenzdateien an das Ziel senden.
